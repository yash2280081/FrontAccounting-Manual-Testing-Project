# FrontAccounting(FA) – Manual Testing Project

## Project Overview

FrontAccounting is a web-based accounting application. This project was performed as part of software testing training to gain hands-on experience in manual testing.

## Role

**Manual Tester**

## Testing Activities

* Studied application functionality and identified test scenarios.
* Prepared and executed test cases.
* Performed positive and negative testing.
* Tested input validations and business rules.
* Tested sales-related functionality.
* Verified Sales Quotation functionality.
* Tested invalid and boundary conditions.
* Compared actual results with expected results.
* Identified and documented defects.
* Prepared defect reports with reproduction steps.
* Assigned Severity and Priority to defects.
* Maintained testing documentation.

## Test Case Design Techniques

* Equivalence Partitioning
* Boundary Value Analysis
* Decision Table Testing
* State Transition Testing
